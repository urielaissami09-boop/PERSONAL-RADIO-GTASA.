# PERSONAL RADIO 0.3.2

Código fuente de un mod nativo para GTA San Andreas Android, ABI `armeabi-v7a`.

La compilación se realiza gratis con GitHub Actions. El workflow descarga las fuentes oficiales de AML, el SDK Android de GTA San Andreas usado por otros mods de AML y el encabezado de interfaz de BASSMod. Después compila `libPersonalRadio.so` y lo empaqueta en `PERSONAL_RADIO_ANDROID.zip`.

Esta versión es un prototipo con controles táctiles propios. Todavía no añade una emisora al selector original de radios. Requiere AML y BASSMod instalados por separado, y debe probarse en el dispositivo antes de considerarla funcional.
